# SageApple Codebase Analysis

## Project Overview
Apple II-inspired retrocomputer emulator in **SageLang**, targeting ATmega328P/Arduino UNO R3.
- Reusable Sage6502 CPU core (151 opcodes, cycle-exact)
- DOS 3.3 command processor
- Full Applesoft BASIC interpreter
- Apple II monitor (`*` prompt)
- SAGEFS v2 filesystem
- 12 classic apps

## Key Features

### Applesoft BASIC (~2180 lines)
- FP math with scientific notation, 16 functions (SQR, LOG, SIN, etc.)
- String functions (ASC, CHR$, LEFT$, RIGHT$, MID$, LEN, STR$, VAL)
- Control: IF/THEN/GOTO, FOR/NEXT, GOSUB/RETURN, ON GOTO/GOSUB
- Data: READ/DATA/RESTORE, DEF FN, DIM arrays
- Error handling: ONERR GOTO/RESUME, Applesoft messages
- Token caching, immediate mode RUN/GOTO promotion

### DOS 3.3 (~748 lines)
- CATALOG with lock markers (`*A 002 NAME`), zero-padded sectors
- File types: A/B/T/I
- BSAVE/BLOAD/BRUN with `A<addr>,L<len>`
- RENAME, LOCK/UNLOCK, MAXFILES 1-16
- MON/NOMON, PR#/IN#
- Error messages: FILE NOT FOUND, TYPE MISMATCH, DIRECTORY FULL vs DISK FULL

### Apple II Monitor (~816 lines)
- `*` prompt via `CALL -151`/`CALL 65449`
- Dump (`800.`), disassembly (`800L`), go (`800G`), JSR (`800J`)
- Store (`800:AA BB`), step (`S`), trace (`T`), display modes (N/I/F)
- `E` exits to BASIC

### SAGEFS v2 (~371 lines)
- 16 entries × 20 bytes (name 12B, size u16, start u16, type, flags)
- Directory: block 0 + 16B of block 1, data from block 2
- First-fit contiguous, format v0x02
- `save_applesoft` (CRLF), `delete` erases data blocks

## Performance Optimizations

| Optimization | Location | Impact |
|--------------|----------|--------|
| `upd_nz` inline bit ops | `flags.sage:88` | ~19% faster |
| `fetch()` scratch buffer | `cpu.sage:329` | No list alloc/instruction |
| UART `tx_text` watermark | `uart.sage:56` | O(n²)→O(n) |
| Bus ROM-first read8 | `applebus.sage:48` | Hot path first |
| Monitor cached `_OPCODES` | `monitor.sage:669` | 40× rebuilds eliminated |
| BASIC token caching | `basic.sage:347` | Re-tokenize on edit only |
