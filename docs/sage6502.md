# Sage6502 — the CPU core

`sage6502/` implements a complete, table-driven interpreter for the NMOS
6502 microprocessor, written in pure SageLang. It is the beating heart of
the project: the same core (conceptually) runs under the host interpreter
and inside the ATmega328P on the real board.

```
sage6502/
├── registers.sage   A/X/Y/SP/PC register object
├── flags.sage       processor status register (NV-BDIZC)
└── cpu.sage         671-line table-driven interpreter
```

## The CPU class

`cpu.sage` defines `CPU` with a `bus` reference — *never* host memory:

| field | meaning |
|---|---|
| `bus` | the memory bus (`Bus` flat or `AppleBus`) |
| `regs` | `Registers` object (a, x, y, sp, pc) |
| `status` | `Status` object (the P register) |
| `halted` | machine is halted (BRK or user request) |
| `cycles` | instruction cycle counter |
| `irq_pending` / `nmi_pending` | soft-latched interrupt requests |

Public API:

```text
reset()                 ; SP=$FD, PC=read16($FFFC), P=B|I, A/X/Y=0
step()                  ; fetch+decode+execute one instruction
run()                   ; step with a 1,000,000-cycle guard
interrupt() / nmi()     ; latch a pending IRQ / NMI
push()/pull()/push16()/pull16()
read8()/write8()/read16()
```

Interrupts are serviced *between* instructions: NMI pushes PC + status,
sets the I flag, and vectors to `$FFFA`; IRQ to `$FFFE` (only when I is
clear). Both account +7 cycles. `BRK` (by design quirk, not real 6502
behavior) sets `halted = true`.

### Instruction set

The opcode space is defined by three tables built at import time:

| table | size | meaning |
|---|---|---|
| `_OPCODES` | 256 | `[instruction_id, addressing_mode]` per opcode byte |
| `_CYCLES` | 256 | base cycle count per opcode byte |
| `_INSN` | — | mnemonic strings (used by documentation/tools) |

There are 56 instruction ids (LDA, LDX, LDY, STA, STX, STY, TAX, TXA, TAY,
TYA, TSX, TXS, PHA, PHP, PLA, PLP, ADC, SBC, AND, ORA, EOR, BIT, CMP, CPX,
CPY, INC, DEC, INX, INY, DEX, DEY, ASL, LSR, ROL, ROR, the 8 branches,
JMP/JSR/RTS, BRK/RTI, NOP, CLC/CLD/CLI/CLV/SEC/SED/SEI) and **13 addressing
modes**:

```
M_IMM=0  M_ZP=1   M_ZPX=2  M_ZPY=3  M_ABS=4
M_ABSX=5 M_ABSY=6 M_INDX=7 M_INDY=8 M_ACC=9
M_IND=10 M_REL=11 M_IMP=12
```

Notes on fidelity:

- zero-page indexed addressing wraps within the zero page;
- absolute indexed (`abs,X` `abs,Y`) and indirect indexed (`(zp),Y`) reads
  charge the +1 cycle page-cross penalty, as does a taken branch whose
  target crosses a page (base `_CYCLES` counts already include the
  RMW/store page-cross cycles, matching the NMOS 6502);
- `JMP ($xxFF)` reproduces the NMOS quirk: the high byte is read back on
  the same page (`$xx00`), not from the next page;
- indirect modes read through zero-page pointers with page-wrap on pointer
  increment;
- undefined opcodes decode to `[0, M_IMP]` and execute as cycle-free no-ops;
- stores (STA/STX/STY — ids 3/4/5) write without the dummy read, so an RX
  input port is never consumed by a store.

### Execution

* `step()` — fetch opcode at PC, PC++, `decode()`, `exec(id, mode)`, add
  `_CYCLES[op]` plus the extra cycles returned by `exec()` (+1 for a taken
  branch, +1 more if the branch target crosses a page, +1 for an indexed
  read crossing a page), then serve a pending interrupt.
* `exec(id, mode)` — immediate / accumulator (shifts on A) / branch /
  implied / memory dispatch.
* Arithmetic — `adc()` / `sbc()` use the canonical overflow formula
  `(a^r)&(operand^r)&0x80`; `compare()` sets C from `reg >= operand`;
  shifts/rotates set C from the bit shifted out.
* `fetch(mode)` computes the effective address for every non-immediate,
  non-implied mode.

## Registers (`registers.sage`)

`Registers` holds:

```text
a, x, y     - 8-bit
sp          - 8-bit (stack page fixed at $0100)
pc          - 16-bit
```

`get_*`/`set_*` mutators mask values to the register width (PC 16-bit, the
rest 8-bit).

## Flags (`flags.sage`)

Single-byte processor status:

```
7 6 5 4 3 2 1 0 =  N V - B D I Z C
```

`Status` exposes `N() V() B() D() I() Z() C()` getters, `set_N()...`
setters using mask-clear semantics, raw `get()/set()/from_byte()`, and
`upd_nz(value)`. Bit 5 is never exposed.

## Ports & uses

* host: `bus.applebus` (via `sageapple/machine.sage`), all tests
* the C port in `avr/sage6502.c` mirrors the dispatch exactly — including
  the opcode→[id, mode] table *and* the base cycle-count table, both
  *generated* from this file by `tools/gen_table.sage`;
* the assembler and the compiler backend array opcode encodings from the
  same canonical NMOS numbers.

Known randomness to preserve: BRK halts the machine; undefined opcodes are
NOPs; cycle accounting is exact for the page-cross penalties above.
